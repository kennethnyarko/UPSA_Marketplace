# Security reporting

This project handles sensitive student-verification information in its approved future scope. Do not report suspected vulnerabilities publicly with personal data, credentials, or exploit payloads.

For a suspected issue, stop the affected test/workflow and privately contact the project owner or designated IT lead. Include only the affected environment, steps using synthetic accounts, expected/actual access, and minimal sanitized evidence. Do not test production or access another student’s real data.

See [`docs/SECURITY.md`](docs/SECURITY.md) for the security model and [`docs/OPERATIONS.md`](docs/OPERATIONS.md) for response ownership. There is no public vulnerability intake service established yet.

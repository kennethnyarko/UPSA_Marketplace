# Design system

**Status: visual direction approved; no styles or tokens implemented.**

The intended direction is **Champagne & Wine**: warm neutral/champagne surfaces with deep wine accents, suitable for a mature, clear university marketplace. Avoid neon, clutter, cartoon styling, excessive gradients, and unapproved UPSA logos or brand claims.

Future centralized tokens belong in `src/styles/tokens.css`; other styles belong in the neighboring placeholder CSS files. The files currently contain comments only—there are no CSS custom properties, colors, typography, components, or responsive designs yet.

When UI work starts, define accessible contrast, typography, spacing, buttons, inputs, cards, navigation, alerts, modals, tables, status labels, loading/error/empty states, and responsive behavior. Do not communicate state by color alone. Follow `ACCESSIBILITY.md`.

# Application source locations

This directory is a map for future application code, not a working application.

- `pages/`: future HTML pages, grouped by product area.
- `components/`: future reusable UI pieces.
- `styles/`: future CSS files and centralized Champagne & Wine design tokens.
- `services/`: future browser-side Firebase client services.
- `state/`, `utils/`, `config/`: future shared browser code and non-secret configuration.

Files here are placeholders only. No Firebase calls, page behavior, or styling has been implemented.
